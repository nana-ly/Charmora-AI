# ShopGuide RAG 体验与部署说明

## 1. 文档目的

本文说明如何通过已部署服务器快速体验 ShopGuide RAG，并保留本地部署、Android 运行和增强能力配置说明。评委优先使用线上服务即可体验核心导购能力；如果现场网络不可用，再按本地部署流程启动后端。

## 2. 推荐体验路线

最快体验路线：

```text
1. 打开线上 Swagger: http://8.137.191.215/docs
2. 调用 /health 和 /ready 确认服务状态
3. 用 Swagger 或 PowerShell 调用 /chat
4. 如需体验 Android，优先使用前端负责人已改为线上地址的待合并版本；当前主线版本可按本文说明手动确认 BASE_URL
```

线上服务当前已经部署完成，服务器地址为：

```text
http://8.137.191.215
```

2026-06-09 已验证：

```text
GET /health -> {"status":"ok"}
GET /ready  -> {"status":"ready","retriever_mode":"vector"}
GET /docs   -> ShopGuide RAG API - Swagger UI
```

本地备用体验路线：

```text
1. 启动 FastAPI 后端
2. 如果没有本地向量索引或 Embedding Key，将后端检索模式切到 keyword
3. 用 Swagger 或 PowerShell 调用 /chat
4. 打开 Android 模拟器体验聊天导购和商品卡片
```

本地 `keyword` 路线不依赖 Embedding API、LLM API 或百度 ASR 凭证，适合离线兜底演示。

增强体验路线：

```text
1. 配置 embedding_api
2. 构建 rag/.chroma/products 向量索引
3. 使用 RETRIEVER_MODE=vector 启动后端
4. 可选配置 LLM_API_KEY 和百度 ASR 凭证
```

## 4. 环境准备

后端必需：

- Python `>=3.12,<3.13`
- `uv`
- Windows PowerShell

Android 必需：

- Android Studio
- JDK 17
- Android 模拟器或 Android 真机

- Embedding API Key，用于向量检索。

## 5. 本地后端启动

进入后端目录并安装依赖：

```powershell
cd backend
uv sync
Copy-Item .env.example .env
```

为了保证评委快速体验不依赖外部 Embedding 服务，建议先把 `backend/.env` 中的检索模式改为：

```env
RETRIEVER_MODE=keyword
```

启动服务：

```powershell
uv run fastapi dev main.py --host 127.0.0.1 --port 8000
```

启动成功后访问：

```text
http://127.0.0.1:8000/docs
```

健康检查：

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:8000/health"
```

推荐依赖检查：

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:8000/ready"
```

如果使用 `RETRIEVER_MODE=vector` 且尚未配置向量索引或 Embedding API，`/ready` 可能返回 HTTP 503，这是预期行为。快速演示时切换到 `keyword` 即可。

### 6.1 多轮导购

```powershell
$baseUrl = "http://8.137.191.215"
$body = @{
  session_id = "judge-demo"
```

## 8. Android 客户端体验

### 8.1 连接线上服务器

前端负责人已经将 Android 客户端连接地址改为线上服务器地址，但该改动当前尚未合并到本仓库主线。评委体验时请优先使用已包含该改动的前端版本；如果使用的是当前主线代码，需要手动确认 `android/app/src/main/java/com/client/shopguide/RetrofitClient.java` 中的 `BASE_URL` 是否为：

```java
private static final String BASE_URL = "http://8.137.191.215/";
```

如果仍是默认模拟器本地地址 `http://10.0.2.2:8000/`，请先切换为线上地址，再用 Android Studio 重新运行 `app`。当前 `AndroidManifest.xml` 已设置 `android:usesCleartextTraffic="true"`，可以访问 HTTP 服务。

### 8.2 本地模拟器体验

1. 先按上文启动后端，确保后端监听：

```text
http://127.0.0.1:8000
```

2. 用 Android Studio 打开 `android/` 目录。

3. 启动 Android 模拟器。

4. 运行 `app`。

Android 端默认后端地址是：

```text
http://10.0.2.2:8000/
```

`10.0.2.2` 是 Android 模拟器访问宿主机 `127.0.0.1` 的特殊地址，因此模拟器场景通常无需改代码。

### 8.3 本地真机体验

真机无法直接访问电脑的 `127.0.0.1`，需要：

1. 手机和电脑连接同一局域网。
2. 获取电脑局域网 IP，例如 `192.168.1.10`。
3. 将 `android/app/src/main/java/com/client/shopguide/RetrofitClient.java` 中的 `BASE_URL` 改为：

```java
private static final String BASE_URL = "http://192.168.1.10:8000/";
```

4. 后端启动时允许局域网访问：

```powershell
cd backend
uv run fastapi dev main.py --host 0.0.0.0 --port 8000
```

5. 重新安装运行 Android App。

真机体验是否可访问还取决于现场网络、防火墙和电脑端口开放情况，需要现场确认。

### 8.4 Android 可体验功能

评委可重点体验：

- 聊天式导购。
- 流式回复和 REST 回退。
- 商品卡片列表。
- 商品详情页。
- 本地购物车 UI。
- 语音转文字输入。

语音输入需要在 `android/.env` 配置百度 ASR 凭证：

```env
BAIDU_APP_ID=
BAIDU_API_KEY=
BAIDU_SECRET_KEY=
```

未配置语音凭证时，文本导购、商品推荐和商品卡片展示不受影响。

## 9. 向量 RAG 增强体验

线上服务当前 `/ready` 返回 `retriever_mode="vector"`，评委可直接通过线上 `/chat`、`/recommend` 和 `/rag/search` 体验向量检索。以下步骤用于本地环境自行构建向量索引。

如果需要展示 Chroma 向量检索能力，先在项目根目录或环境变量中配置：

```env
embedding_url=https://dashscope.aliyuncs.com/compatible-mode/v1
embedding_api=<your_embedding_api_key>
embedding_model=text-embedding-v4
embedding_dimensions=1024
```

构建索引：

```powershell
cd rag
uv sync
uv run python -m shopguide_rag.cli index
```

索引默认写入：

```text
rag/.chroma/products
```

然后修改 `backend/.env`：

```env
RETRIEVER_MODE=vector
```

重启后端并检查：

```powershell
cd backend
uv run fastapi dev main.py --host 127.0.0.1 --port 8000
Invoke-RestMethod -Uri "http://127.0.0.1:8000/ready"
```

如果 `/ready` 返回 `status="ready"`，即可通过 `/recommend`、`/chat` 和 `/rag/search` 体验向量检索。

## 10. LLM 增强体验

后端默认 `LLM_ENABLED=false`，这样本地最小闭环不依赖外部大模型。

如需启用真实 LLM，在 `backend/.env` 中配置：

```env
LLM_ENABLED=true
LLM_API_KEY=<your_llm_api_key>
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o-mini
LLM_TIMEOUT_SECONDS=60
```

启用后，LLM 会参与用户理解和可选理由生成，但商品推荐结果仍由后端商品数据、过滤、检索和排序链路控制。

## 13. 常见问题

### 线上服务器无法访问

先访问：

```text
http://8.137.191.215/health
```

如果无法访问，可能是服务器、网络、防火墙或现场网络策略问题。此时可切换到本地部署路线，使用 `http://127.0.0.1:8000` 继续演示。

### `/ready` 返回 503

通常是因为当前使用 `RETRIEVER_MODE=vector`，但还没有配置 Embedding API 或构建 Chroma 索引。快速体验时将 `backend/.env` 改为：

```env
RETRIEVER_MODE=keyword
```

然后重启后端。

### Android 模拟器连不上后端

如果连接线上服务器，优先确认当前使用的前端版本是否已经合入服务器地址改动；若未合入，请确认 `RetrofitClient.BASE_URL` 已改为：

```text
http://8.137.191.215/
```

如果连接本地后端，检查后端是否启动在 `127.0.0.1:8000`。模拟器访问宿主机应使用：

```text
http://10.0.2.2:8000/
```

该地址已经写在当前 `RetrofitClient.java` 中。

### Android 真机连不上后端

真机需要使用电脑局域网 IP，并用 `--host 0.0.0.0` 启动后端。还需要确认 Windows 防火墙或安全软件没有阻止 `8000` 端口。

### 商品图片不显示

后端默认通过 `/assets/products` 挂载 `ecommerce_agent_dataset` 下的商品图片。确认：

```env
PRODUCT_IMAGE_STATIC_ENABLED=true
PRODUCT_IMAGE_BASE_URL=/assets/products
PRODUCT_IMAGE_STATIC_ROOT=../ecommerce_agent_dataset
```

如果改为 CDN 或对象存储，需要保证后端返回的 `image_url` 可被 Android 访问。

### 语音输入不可用

语音输入依赖百度 ASR 凭证。未配置凭证时，文本输入和商品推荐仍可正常体验。

## 14. 当前体验边界

- 跨机器生产级会话存储。
