# ShopGuide RAG 体验与部署说明

## 1. 文档目的

本文说明如何在本地部署 ShopGuide RAG，并给出评委快速体验路径。为了降低演示依赖，推荐先使用 `RETRIEVER_MODE=keyword` 跑通后端和 Android 客户端；如需展示向量 RAG 和真实 LLM，再按增强体验章节配置外部服务。

## 2. 推荐体验路线

最快体验路线：

```text
1. 启动 FastAPI 后端
2. 将后端检索模式切到 keyword
3. 用 Swagger 或 PowerShell 调用 /chat
4. 打开 Android 模拟器体验聊天导购和商品卡片
```

这条路线不依赖 Embedding API、LLM API 或百度 ASR 凭证，适合评委快速跑通。

增强体验路线：

```text
1. 配置 embedding_api
2. 构建 rag/.chroma/products 向量索引
3. 使用 RETRIEVER_MODE=vector 启动后端
4. 可选配置 LLM_API_KEY 和百度 ASR 凭证
```

## 3. 环境准备

后端必需：

- Python `>=3.12,<3.13`
- `uv`
- Windows PowerShell

Android 必需：

- Android Studio
- JDK 17
- Android 模拟器或 Android 真机

可选：

- Embedding API Key，用于向量检索。
- LLM API Key，用于真实 LLM 理解和理由生成。
- 百度 ASR 凭证，用于语音输入。

## 4. 后端快速启动

进入后端目录并安装依赖：

```powershell
cd backend
uv sync
Copy-Item .env.example .env
```

为了保证评委快速体验不依赖外部 Embedding 服务，建议先把 `backend/.env` 中的检索模式改为：

```env
RETRIEVER_MODE=keyword
```

启动服务：

```powershell
uv run fastapi dev main.py --host 127.0.0.1 --port 8000
```

启动成功后访问：

```text
http://127.0.0.1:8000/docs
```

健康检查：

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:8000/health"
```

推荐依赖检查：

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:8000/ready"
```

如果使用 `RETRIEVER_MODE=vector` 且尚未配置向量索引或 Embedding API，`/ready` 可能返回 HTTP 503，这是预期行为。快速演示时切换到 `keyword` 即可。

## 5. API 快速体验

Invoke-RestMethod `

## 6. SSE 流式体验

项目提供了一个后端手动聊天 CLI，方便评委直接体验 `/chat/stream`：

```powershell
cd backend
uv run python tests/manual_chat_cli.py --mode stream --session judge-stream
```

进入 CLI 后可以输入：

```text
预算9000以内，推荐拍照好的手机
不要第一个
为什么第二个适合我
推荐一款敏感肌面霜
回到刚才的手机需求
```

如果流式请求失败，CLI 会自动回退到 REST `/chat`。

也可以直接使用 REST 模式：

```powershell
cd backend
uv run python tests/manual_chat_cli.py --mode rest --session judge-rest
```

## 7. Android 客户端体验

### 7.1 模拟器体验

1. 先按上文启动后端，确保后端监听：

```text
http://127.0.0.1:8000
```

2. 用 Android Studio 打开 `android/` 目录。

3. 启动 Android 模拟器。

4. 运行 `app`。

Android 端默认后端地址是：

```text
http://10.0.2.2:8000/
```

`10.0.2.2` 是 Android 模拟器访问宿主机 `127.0.0.1` 的特殊地址，因此模拟器场景通常无需改代码。

### 7.2 真机体验

真机无法直接访问电脑的 `127.0.0.1`，需要：

1. 手机和电脑连接同一局域网。
2. 获取电脑局域网 IP，例如 `192.168.1.10`。
3. 将 `android/app/src/main/java/com/client/shopguide/RetrofitClient.java` 中的 `BASE_URL` 改为：

```java
private static final String BASE_URL = "http://192.168.1.10:8000/";
```

4. 后端启动时允许局域网访问：

```powershell
cd backend
uv run fastapi dev main.py --host 0.0.0.0 --port 8000
```

5. 重新安装运行 Android App。

真机体验是否可访问还取决于现场网络、防火墙和电脑端口开放情况，需要现场确认。

### 7.3 Android 可体验功能

评委可重点体验：

- 聊天式导购。
- 流式回复和 REST 回退。
- 商品卡片列表。
- 商品详情页。
- 本地购物车 UI。
- 语音转文字输入。

语音输入需要在 `android/.env` 配置百度 ASR 凭证：

```env
BAIDU_APP_ID=
BAIDU_API_KEY=
BAIDU_SECRET_KEY=
```

未配置语音凭证时，文本导购、商品推荐和商品卡片展示不受影响。

## 8. 向量 RAG 增强体验

如果需要展示 Chroma 向量检索能力，先在项目根目录或环境变量中配置：

```env
embedding_url=https://dashscope.aliyuncs.com/compatible-mode/v1
embedding_api=<your_embedding_api_key>
embedding_model=text-embedding-v4
embedding_dimensions=1024
```

构建索引：

```powershell
cd rag
uv sync
uv run python -m shopguide_rag.cli index
```

索引默认写入：

```text
rag/.chroma/products
```

然后修改 `backend/.env`：

```env
RETRIEVER_MODE=vector
```

重启后端并检查：

```powershell
cd backend
uv run fastapi dev main.py --host 127.0.0.1 --port 8000
Invoke-RestMethod -Uri "http://127.0.0.1:8000/ready"
```

如果 `/ready` 返回 `status="ready"`，即可通过 `/recommend`、`/chat` 和 `/rag/search` 体验向量检索。

## 9. LLM 增强体验

后端默认 `LLM_ENABLED=false`，这样本地最小闭环不依赖外部大模型。

如需启用真实 LLM，在 `backend/.env` 中配置：

```env
LLM_ENABLED=true
LLM_API_KEY=<your_llm_api_key>
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o-mini
LLM_TIMEOUT_SECONDS=60
```

启用后，LLM 会参与用户理解和可选理由生成，但商品推荐结果仍由后端商品数据、过滤、检索和排序链路控制。

## 10. 评委推荐演示脚本

建议演示顺序：

1. 打开 `http://127.0.0.1:8000/docs`，展示接口列表。
2. 调用 `/ready`，说明当前使用 `keyword` 或 `vector` 检索模式。
3. 调用 `/chat` 输入“预算9000以内，推荐拍照好的手机，不要苹果”，展示结构化商品卡片。
4. 输入“不要第二个，换一批”，展示负反馈排除能力。
5. 输入“为什么第一个适合我”，展示基于上一轮真实商品的解释能力。
6. 输入“对比第一个和第二个”，展示商品对比能力。
7. 输入“推荐敏感肌面霜”，展示跨品类切换。
8. 输入“回到刚才的手机需求”，展示历史上下文恢复确认。
9. 打开 Android App，重复一到两个核心问题，展示移动端商品卡片和详情页。

推荐问题样例：

```text
预算9000以内，推荐拍照好的手机，不要苹果
不要第二个，换一批
为什么第一个适合我
对比第一个和第二个
推荐一款敏感肌面霜
推荐适合跑步的鞋
预算200以内，有没有适合作为早餐的食品
```

## 12. 常见问题

### `/ready` 返回 503

通常是因为当前使用 `RETRIEVER_MODE=vector`，但还没有配置 Embedding API 或构建 Chroma 索引。快速体验时将 `backend/.env` 改为：

```env
RETRIEVER_MODE=keyword
```

然后重启后端。

### Android 模拟器连不上后端

检查后端是否启动在 `127.0.0.1:8000`。模拟器访问宿主机应使用：

```text
http://10.0.2.2:8000/
```

该地址已经写在当前 `RetrofitClient.java` 中。

### Android 真机连不上后端

真机需要使用电脑局域网 IP，并用 `--host 0.0.0.0` 启动后端。还需要确认 Windows 防火墙或安全软件没有阻止 `8000` 端口。

### 商品图片不显示

后端默认通过 `/assets/products` 挂载 `ecommerce_agent_dataset` 下的商品图片。确认：

```env
PRODUCT_IMAGE_STATIC_ENABLED=true
PRODUCT_IMAGE_BASE_URL=/assets/products
PRODUCT_IMAGE_STATIC_ROOT=../ecommerce_agent_dataset
```

如果改为 CDN 或对象存储，需要保证后端返回的 `image_url` 可被 Android 访问。

### 语音输入不可用

语音输入依赖百度 ASR 凭证。未配置凭证时，文本输入和商品推荐仍可正常体验。

## 13. 当前体验边界

当前项目适合展示智能导购、商品推荐、负反馈、多轮上下文和移动端商品卡片闭环。以下能力不建议作为已完成能力演示：

- 图片上传后的多模态理解。
- 真实下单、库存、支付和物流。
- 用户登录、权限体系和生产级限流。
- 跨机器生产级会话存储。
