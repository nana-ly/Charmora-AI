# 绮饰集 Charmora UI 原型

这是 Android 商城改版前的可点击视觉原型，主色为灰调玫瑰粉、雾紫和暖白，不使用纯黑作为界面色。

## 本地预览

在仓库根目录启动静态服务器：

```powershell
py -3 -m http.server 4173 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:4173/docs/ui-prototype/index.html
```

当前原型已覆盖首页、分类与筛选、商品详情、收藏、AI 选购、购物车数量调整、配送到家/到店自取结算、订单状态时间线和会员中心。所有一级页面共用固定底部导航，AI 选购不会跳出商城壳层。
