项目名称：实现一个基于RAG的多模态智能导购系统

## 当前代码实现摘要

当前仓库已实现 Android 原生客户端、FastAPI 后端、商品 JSON 数据加载、关键词/向量检索、单轮推荐、多轮导购 Agent、SSE 流式对话、负反馈排除、上下文归档/恢复、商品解释/对比和离线评测脚本。后端接口以 `docs/api.md` 为准，后端架构以 `docs/后端技术文档.md` 为准。

当前代码中可以确认的客户端输入以文字和语音转文字为主；图片输入解析、上传非结构化文档动态构建知识库、真实购物车下单闭环等能力属于课题目标或后续扩展方向，尚不能从当前后端接口中确认完成。相关表述应按“规划目标/待核实”理解。

## 原始课题目标

项目任务：基于 iOS/Android 原生框架、Node.js/Python/Go 等后端服务、向量数据库及大模型 OpenAPI 等技术栈，构建一个打通"意图理解-智能咨询-决策辅助"核心路径的电商 AI 导购系统。 要求实现一个能够深度理解商品属性、用户意图并提供个性化决策支持的智能 Agent。通过上传非结构化的商品详情与营销文档构建专属知识库，系统通过 RAG 技术确保回复的专业性与准确性；在客户端，需利用原生技术栈打造媲美"豆包"的流式交互体验，同时支持商品卡片实时渲染、多模态（文字/图片）输入解析。 同时，课题需构建一套端到端的质量评测与反馈闭环，通过对典型导购场景下的回答准确率、知识检索精度及多轮对话逻辑进行定量评估，反哺 Prompt 策略优化与知识库迭代，旨在验证该工程方案在模拟商业场景下的技术可行性与交互质量，并为电商导购从"信息搜索"向"辅助决策"的代际跨越提供工程实践参考。

开发周期：3 周
